Cách hoạt động

Trang này đọc dữ liệu hiện có của website. Bạn thêm, sửa, xóa bài viết hoặc cán bộ ngay tại đây, rồi:

  1. Bấm nút xanh "Tải về các file đã thay đổi" → các file được tải về máy.
  2. Dùng FileZilla kéo các file đó lên máy chủ của trường.
Thay đổi chưa có trên website cho tới khi bạn làm xong 2 bước trên. Đừng đóng trang khi còn thanh màu vàng "Có thay đổi chưa đưa lên website".

1. Mở trang quản trị

  • Cách đơn giản nhất: mở trình duyệt, gõ địa chỉ website rồi thêm /admin/ ở cuối. Dữ liệu được đọc tự động và luôn là bản mới nhất trên web.
  • Hoặc trên máy tính: nháy đúp file admin/index.html trong thư mục website → chọn 2 file data/data.json và data/staff.json khi được hỏi.
Mẹo: lưu trang này vào dấu trang (bookmark, Ctrl+D) để lần sau mở nhanh.

2. Đăng, sửa, xóa bài viết

Tab Bài viết → bấm Viết bài mới:

  • Chọn chuyên mục, ngày đăng, nhập tiêu đề và tóm tắt (1–2 câu, hiện ở trang chủ).
  • Ảnh đại diện: bấm Chọn ảnh..., chọn ảnh bất kỳ trên máy. Ảnh tự được thu nhỏ và đặt tên.
  • Nội dung: gõ như bình thường, mỗi dòng là một đoạn văn. Muốn chèn ảnh giữa bài: đặt con trỏ vào chỗ cần chèn → bấm Chèn ảnh (chọn được nhiều ảnh một lúc).
  • Bôi đen chữ rồi bấm B để in đậm, I để in nghiêng; Chèn link để thêm đường dẫn.
  • Khung Xem trước bên phải cho thấy bài sẽ hiển thị ra sao → bấm Lưu bài.

Sửa: bấm Sửa ở dòng bài viết. Xóa: bấm nút thùng rác. Bài mới nhất (theo ngày đăng) tự lên đầu trang chủ.

3. Thêm, sửa cán bộ

  • Tab Cán bộ → Thêm cán bộ hoặc Sửa: điền họ tên kèm học vị (vd. TS. Nguyễn Văn A), bộ môn, chức vụ, email, ảnh chân dung, quá trình đào tạo...
  • Mũi tên đổi thứ tự hiển thị trên web.
  • Khi đổi trưởng bộ môn / trưởng khoa: nhớ bỏ chức vụ của người cũ.
  • Cán bộ có chữ đỏ Thiếu ảnh: bấm Sửa → Chọn ảnh... để bổ sung.

4. Đưa thay đổi lên website bằng FileZilla

  1. Bấm "Tải về các file đã thay đổi". Nếu trình duyệt hỏi "Tải xuống nhiều tệp?" → bấm Cho phép.
  2. Trang hiện bảng "File vừa tải về → thư mục trên máy chủ", ví dụ data.json → data/, tin-tuc-000006.jpg → graph/.
  3. Mở FileZilla, kết nối tới máy chủ của trường. Khung trái (máy bạn): mở thư mục Downloads / Tải xuống. Khung phải (máy chủ): mở thư mục website.
  4. Với mỗi dòng trong bảng: mở đúng thư mục bên phải (data hoặc graph), kéo file từ trái sang phải. Được hỏi file đã tồn tại → chọn Overwrite (Ghi đè) → OK.
  5. Mở website, nhấn Ctrl+F5 để kiểm tra.
Lưu ý tên file: nếu Downloads đã có file cũ trùng tên, trình duyệt sẽ đặt tên mới kiểu data (1).json. Hãy xóa file cũ / đổi tên lại cho đúng (data.json, staff.json...) trước khi kéo lên. Cách tốt nhất: xóa data.json, staff.json cũ trong Downloads sau mỗi lần cập nhật.
Nên chép thêm các file vừa tải vào đúng thư mục trong bản website trên máy (nếu có) để bản trên máy luôn giống web.

5. Menu, chân trang và các trang giới thiệu

Các phần này ít khi thay đổi và cần sửa trực tiếp file (nên nhờ người biết HTML cơ bản). Sửa bằng Notepad++ hoặc VS Code, lưu với mã hóa UTF-8, rồi tải file đó lên bằng FileZilla.

  • Menu, địa chỉ, email, điện thoại ở chân trang: file js/layout.js, sửa phần MENU và FOOTER ở đầu file. Sửa một lần là mọi trang đều đổi theo.
  • Nội dung trang giới thiệu, đào tạo, bộ môn...: file tương ứng trong pages/, chỉ sửa phần nằm giữa <main id="main-content"> và </main>.
  • Thêm trang mới: sao chép một file trong pages/ (vd. tong-quan.html), đổi tên (không dấu, không khoảng trắng), sửa <title> và nội dung, thêm link vào MENU trong js/layout.js, rồi tải cả 2 file lên.
