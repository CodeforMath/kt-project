Quản trị website Khoa Toán

Bắt đầu

  1. Bấm nút bên dưới và chọn thư mục website trên máy tính (thư mục có index.html, data, graph...).
  2. Trình duyệt hỏi quyền sửa file → bấm "Cho phép" / "Lưu thay đổi".
  3. Thêm, sửa bài viết hoặc cán bộ. Mọi thay đổi được lưu ngay vào thư mục đó.
  4. Dùng FileZilla tải những file được liệt kê ở khung màu vàng lên máy chủ.

Lần đầu sử dụng? Bấm Hướng dẫn để xem chi tiết từng bước.

    Nguyên tắc chung

    1. Luôn sửa trên bản website trong máy tính của bạn, sau đó dùng FileZilla tải lên máy chủ của trường.
    2. Bài viết và cán bộ: dùng trang này. Không cần biết lập trình.
    3. Nếu nhiều người cùng quản lý: trước khi sửa, hãy lấy bản mới nhất từ máy chủ về để không ghi đè mất thay đổi của người khác.

    1. Mở trang quản trị

    1. Mở thư mục website trên máy → vào thư mục admin → nháy đúp file index.html.
      Phải mở bằng Microsoft Edge hoặc Google Chrome (nếu máy mở bằng trình duyệt khác: chuột phải → Open with → chọn Edge/Chrome).
    2. Bấm "Chọn thư mục website" → chọn thư mục có index.html, data, graph → bấm Chọn thư mục / Select Folder.
    3. Trình duyệt hỏi quyền → bấm "Cho phép" / "Lưu thay đổi" / "Edit files".

    Từ lần sau chỉ cần bấm "Mở lại thư mục..." rồi bấm Cho phép.

    Mẹo: chuột phải vào admin/index.html → Send to → Desktop (create shortcut) để có biểu tượng ngoài màn hình.

    2. Đăng, sửa, xóa bài viết

    Thẻ Bài viết → bấm Viết bài mới:

    • Chọn chuyên mục, ngày đăng, nhập tiêu đề và tóm tắt (1–2 câu hiện ở trang chủ).
    • Ảnh đại diện: bấm Chọn ảnh..., chọn ảnh bất kỳ trên máy. Ảnh tự được thu nhỏ, đặt tên và chép vào thư mục graph/.
    • Nội dung: gõ như bình thường, mỗi dòng là một đoạn văn. Muốn chèn ảnh giữa bài: đặt con trỏ vào chỗ cần chèn → bấm Chèn ảnh (chọn được nhiều ảnh một lúc).
    • Bôi đen chữ rồi bấm B để in đậm, I để in nghiêng; Chèn link để thêm đường dẫn.
    • Khung Xem trước bên phải cho thấy bài sẽ hiển thị ra sao → bấm Lưu bài.

    Sửa: bấm Sửa ở dòng bài viết. Xóa: bấm nút thùng rác. Bài mới nhất (theo ngày đăng) tự lên đầu trang chủ.

    Sau khi lưu, bài mới chỉ có trên máy bạn. Phải tải lên bằng FileZilla thì website mới thay đổi.

    3. Thêm, sửa cán bộ

    • Thẻ Cán bộ → Thêm cán bộ hoặc Sửa: điền họ tên kèm học vị (vd. TS. Nguyễn Văn A), bộ môn, chức vụ, email, ảnh chân dung, quá trình đào tạo...
    • Mũi tên đổi thứ tự hiển thị trên web.
    • Khi đổi trưởng bộ môn / trưởng khoa: nhớ bỏ chức vụ của người cũ.
    • Cán bộ có chữ đỏ Thiếu ảnh: bấm Sửa → Chọn ảnh... để bổ sung.

    Các trang Đội ngũ cán bộ, Cơ cấu tổ chức và trang thông tin từng giảng viên tự cập nhật theo.

    4. Tải thay đổi lên máy chủ bằng FileZilla

    Sau khi lưu, trang này hiện khung màu vàng liệt kê các file đã thay đổi, ví dụ data/data.json, graph/tin-tuc-000006.jpg.

    1. Mở FileZilla và kết nối tới máy chủ của trường.
    2. Khung bên trái (máy bạn): mở thư mục website. Khung bên phải (máy chủ): mở thư mục website trên máy chủ.
    3. Với mỗi file trong khung vàng: vào đúng thư mục đó ở cả hai bên (vd. data ↔ data, graph ↔ graph) rồi kéo file từ trái sang phải. Nếu được hỏi file đã tồn tại → chọn Overwrite (Ghi đè) → OK.
    4. Mở website kiểm tra (nhấn Ctrl + F5 để tải lại). Nếu đúng, quay lại đây bấm "Tôi đã tải lên xong".
    Cẩn thận: không kéo cả thư mục data hay graph vào bên trong thư mục cùng tên trên máy chủ (sẽ thành data/data/... và web không nhận).

    5. Lấy bản mới nhất từ máy chủ về máy

    Dùng khi mới nhận bàn giao, đổi máy tính, hoặc có người khác vừa cập nhật web:

    1. Trong FileZilla, ở khung bên phải chọn thư mục data và graph trên máy chủ.
    2. Kéo sang thư mục website ở khung bên trái → chọn Overwrite.
    3. Nếu trang quản trị đang mở: tải lại trang (F5) rồi bấm "Mở lại thư mục...".

    6. Menu, chân trang và các trang giới thiệu

    Các phần này ít khi thay đổi và cần sửa trực tiếp file (nên nhờ người biết HTML cơ bản). Sửa bằng Notepad++ hoặc VS Code, lưu với mã hóa UTF-8.

    • Menu, địa chỉ, email, điện thoại ở chân trang: mở js/layout.js, sửa phần MENU và FOOTER ở đầu file. Sửa một lần là mọi trang đều đổi theo. Sau đó tải js/layout.js lên máy chủ.
    • Nội dung trang giới thiệu, đào tạo, bộ môn...: mở file tương ứng trong pages/, chỉ sửa phần nằm giữa <main id="main-content"> và </main>, rồi tải file đó lên.
    • Thêm trang mới: sao chép một file trong pages/ (vd. tong-quan.html), đổi tên (không dấu, không khoảng trắng), sửa <title> và nội dung, thêm link vào MENU trong js/layout.js, rồi tải cả 2 file lên.

    7. Khi gặp sự cố

    Hiện tượngCách xử lý
    Web không đổi sau khi tải lênNhấn Ctrl + F5. Kiểm tra file đã vào đúng thư mục trên máy chủ chưa.
    Báo "không phải thư mục website"Chọn đúng thư mục chứa index.html (không chọn data hay admin).
    Báo file "bị lỗi định dạng"File dữ liệu bị sửa tay sai. Lấy lại bản trên máy chủ.
    Báo trình duyệt chưa hỗ trợMở bằng Edge hoặc Chrome, và mở file từ máy tính (không mở qua địa chỉ web).
    Không chọn được ảnh từ iPhone (HEIC)Chuyển ảnh sang JPG trước, hoặc gửi ảnh qua Zalo rồi lưu lại.
    Mở index.html trên máy không thấy tin tứcBình thường — trình duyệt chặn đọc dữ liệu khi mở file trực tiếp. Hãy xem trên web thật.
